# Escuela de Enfermería · Universidad de Oriente

Plataforma educativa de apoyo para estudiantes de Enfermería. Incluye Fundamentos de Enfermería I, guías de estudio, procedimientos, autoevaluación y recursos académicos.

## Sitio público

La publicación mediante GitHub Pages se está configurando. El portal no contiene logotipos oficiales ni protocolos clínicos institucionales; el material es educativo y debe complementarse con la guía docente y los protocolos vigentes.
