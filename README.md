# Escuela de Enfermería · Universidad de Oriente

Plataforma educativa de apoyo para estudiantes de Enfermería. Incluye Fundamentos de Enfermería I, guías de estudio, procedimientos, autoevaluación, recursos académicos y una actividad interactiva de clasificación de RPBI.

## Sitio público

El sitio se publica con GitHub Pages y el código fuente está disponible en el repositorio de GitHub:

- Sitio público: https://mtroeriktimal.github.io/enfermeria-uo/
- https://github.com/MtroErikTimal/enfermeria-uo

El portal es material educativo y debe complementarse con la guía docente y los protocolos institucionales vigentes.
